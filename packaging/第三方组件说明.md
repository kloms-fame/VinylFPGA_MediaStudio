# 随包组件

- Python 3.13.12 与标准库：由 PyInstaller 收集运行时；许可随运行时包含。
- Pillow 13.0.0：图像读取、裁剪与点阵处理，HPND 许可。包中保留其分发许可。
- PyInstaller 6.22.3：构建工具，GPL 许可附带对生成应用的例外；不要求用户安装 Python。
- FFmpeg/FFprobe：8.0.1 essentials Windows static build，来源 www.gyan.dev。该分发标注 GPL v3，随包 `resources/bin/FFmpeg-LICENSE.txt` 与 `FFmpeg-README.txt` 保留版本、构建配置和准确源代码提交链接。原始来源：[gyan.dev](https://www.gyan.dev/ffmpeg/builds/)。
- Noto Sans CJK SC Regular：来源 notofonts/noto-cjk 的 SimplifiedChinese OTF，SIL Open Font License 1.1；字体旁保留 `OFL.txt`，生成版本清单记录 SHA-256。来源：[Noto CJK](https://github.com/notofonts/noto-cjk)。
- `vendor/` 三项工程工具：复制自本项目 `c5b01c0`，`PROVENANCE.json` 记录源路径与 SHA-256。
- `profiles/frozen/` 为本项目已验收固件对应的点阵 ROM、规格和显示 RTL 快照；不含厂商加密 HDL IP。

完整源代码与便携包一并保存在本工具目录。Playwright 仅用于开发时界面测试，不进入运行时发布包。
