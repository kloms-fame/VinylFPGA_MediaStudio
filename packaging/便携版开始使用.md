# Windows 便携版

把本文件夹完整解压到可写目录，双击 `VinylFPGA_MediaStudio.exe`。保留旁边的 `_internal/`，无需安装 Python、Node 或 FFmpeg。需要系统已安装浏览器。

素材项目保存在本文件夹的 `projects/`；新建后按界面导入素材并生成镜像。此空白便携包不含现有四曲音视频。源码交付目录的 `启动工具.cmd` 则会打开已经预置的四曲项目。

详细操作参见随包 `使用说明.md`。其中源码、测试、证据和 `release/` 路径属于完整源码交付目录；便携版运行资源在 `_internal/`。依赖哈希、原字体及许可均随 `_internal/resources/` 保存。

预览从最终镜像和配套 ROM 读取 640×480 原始像素。“实板逐像素对照”接受同状态的原始 HDMI PNG，仅在差异为 0 时确认该图像对一致。离线预览不自动读取运行中板卡状态。

修改中文标题或歌词请选择自定义 ROM，并重新编译、烧录对应 FPGA 固件；单独写卡不会更新固件文字。写卡前核实目标磁盘号和容量；写入及完整回读结束后再移除 SD 卡。

退出请点击左侧“退出工具”，关闭浏览器标签本身不停止服务。
